👩‍🏫 Teacher Instructions

In the Classroom

Rote counting (reciting "one, two, three...") is a different skill from one-to-one correspondence (pointing to each object as it's counted, and stopping at the right number). This worksheet targets the second, harder skill. Have students physically point to or touch each object as they count aloud rather than counting silently — this makes it easy to spot a student who's reciting numbers without actually tracking which objects have been counted.

👨‍👩‍👧 Parent Instructions

At Home

Counting out loud together while pointing to each item builds the habit before asking a child to do it independently on paper. If a child consistently miscounts by one (a very common early pattern), it's often because they're either skipping an object or double-counting one — slowing down and pointing more deliberately usually fixes it faster than repeating the whole exercise. See our Math Hub for more number sense games at this stage.

✅ What Successful Completion Looks Like

Not a Traditional "Answer Key"

Exact quantities on this sheet will vary by the specific print, so there's no single number key to share here. Instead, check that the counted total matches the number of objects actually pictured, and that the written numeral matches that count. Off-by-one errors are common and expected at this stage — they usually resolve with more pointing-based counting practice, not repetition of the same sheet.
