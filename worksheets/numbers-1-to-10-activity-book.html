👩‍🏫 Teacher Instructions

In the Classroom

Unlike our counting and number recognition worksheet, which isolates one-to-one counting from numeral recognition, this activity book bundles five distinct number skills onto a single page per number: a directional numeral trace with arrows, an object-counting picture, a maze that ends at the correct numeral, a grid to find and color all instances of the number, and a number-word trace ("one," "two," and so on). Use it as a review station once a number has already been introduced individually.

👨‍👩‍👧 Parent Instructions

At Home

Because each page covers five skills, one number per sitting is plenty — this isn't meant to be rushed through like a single-skill worksheet. If your child already traces numbers confidently, let them start with the maze and number-search grid instead, since those two sections double as a quick check on whether the numeral is recognized reliably, not just formed correctly.

✅ What Successful Completion Looks Like

Not a Traditional "Answer Key"

Each maze has one correct path to the matching numeral, and each number-search grid has a fixed set of boxes containing that number. Watch for a child solving the maze by trial and error without reading the numeral at the start and end — pointing to both numerals before tracing the path keeps the exercise connected to number recognition, not just maze-solving.
