📹 Security Camera

Discover the Security Camera!

A Security Camera is a piece of technology used for watching and recording an area to help keep it safe. Electronics like this use electricity and clever engineering to make our lives easier and more fun!

🔌 How Does a Security Camera Work?

A security camera is built for watching and recording an area to help keep it safe. Even though it might seem like magic, every electronic device works using science, electricity, and clever design.

🌟 Fun Facts about Security Camera

  • Security cameras, also called CCTV, record video to help keep places safe.
  • You can often see security cameras in stores, schools, and parking lots.
  • Some security cameras can send video straight to a phone or computer.
  • CCTV stands for "closed-circuit television."

🌟 Why the Security Camera is Useful

People use the security camera every day to make tasks easier and more fun. Understanding how gadgets like this work is the first step to becoming a future inventor or engineer!
