Letter N for Kids

The letter N is the fourteenth letter of the alphabet. Capital N looks like N and small n looks like n. The letter N makes a “nnn” sound.

Words That Start With N

Nest
Nose
Net
Nurse
Night

The letter N helps children learn nose and tongue sounds clearly.

How To Write Letter N

To write capital N, draw two straight lines and one slant line. To write small n, draw one hump.

Fun Facts About Letter N

  • N is used in many common words.
  • N sounds through the nose.

Practice Letter N

Kids can trace N, color N objects, and read N words.
