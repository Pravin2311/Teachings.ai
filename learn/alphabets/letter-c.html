Letter C for Kids

The letter C is the third letter of the English alphabet. Capital C looks like C and small c looks like c. The letter C makes a “kuh” sound.

Words That Start With C

Cat
Car
Cake
Cow
Cloud

These words help children recognize the letter C and improve reading skills.

How To Write Letter C

To write capital C, draw a big curve. To write small c, draw a smaller curve.

Fun Facts About Letter C

  • C is the third letter of the alphabet.
  • C comes after B and before D.
  • Many animal names start with C.

Practice Letter C

Kids can trace, color and read words starting with C.

The Letter C Sound

Letter C usually makes a hard "kuh" sound, as in cat and car. It can also make a soft "s" sound, as in city and circle, when it's followed by e, i, or y. Preschoolers typically learn the hard C sound first, with the soft sound introduced once they're comfortable.

Classroom Activity

Send children on a room scavenger hunt for C objects — a cup, a crayon, a chair. Gather the finds on a table and have the class name each one together, emphasizing the "kuh" sound at the start.

Homeschool Activity

Decorate a pretend paper cupcake or cake together while saying "C is for cake!" Afterward, trace the letter C on paper, drawing the same curved shape used to frost the cake.

Tips for Parents & Teachers

Parents: Since C makes two different sounds, don't worry if your child is confused at first — focus on the hard "kuh" sound until it's solid, then introduce the soft sound with words like city.
Teachers: Letter C is a great confidence-builder since both the capital and lowercase forms are just a single curve — perfect for early tracing practice.

Frequently Asked Questions

What sound does the letter C make?

Letter C usually makes a hard "kuh" sound, as in cat and car. It can also make a soft "s" sound, as in city and circle, depending on the letter that follows it.

What are some easy words that start with C for preschoolers?

Easy C words for preschoolers include cat, car, cake, cow, and cloud — animal and food words are especially memorable for young learners.

How do I teach my child to write the letter C?

Letter C is one of the easier letters to start with since both the capital and lowercase are just a single curve. Practice a big curve for capital C and a smaller curve for lowercase c, starting from the top each time.

Why does C sometimes sound like S?

C makes a soft "s" sound when followed by e, i, or y (city, cent, cycle), and a hard "k" sound before a, o, or u (cat, cot, cup) — worth pointing out once the basic hard C sound is solid.

What activities help kids remember the letter C?

A room scavenger hunt for C objects, tracing C in sand or shaving cream, decorating a pretend cake while saying "C is for cake," or coloring pictures of C words while saying each one aloud.
