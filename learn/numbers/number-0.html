Number 0 (Zero) for Kids: Counting, Writing and Fun Facts

0 is written in words as zero. It means having no things at all. Zero comes just before 1 (one). 0 is an even number.

How to Write the Number 0

  1. Start at the top.
  2. Curve down and around to the left.
  3. Keep going around the bottom and back up to the top to close a tall oval.

The word is spelled Z-E-R-O. Practice tracing 0 in the tracing game or on the Number Writing Practice worksheet.

Zero in Real Life

  • An empty plate has zero cookies
  • A score of 0 means no points yet
  • The 0 key on a phone or keyboard

Fun Facts About 0

  • Zero means none or nothing. If you have zero apples, you have no apples.
  • Adding zero to a number does not change it: 5 + 0 = 5.
  • Zero is an even number.
  • Using zero as a number of its own was developed by mathematicians in ancient India about 1,400 years ago.

Quick Quiz: Number 0

Answer each question, then tap it to check.

What number comes right after 0?

1 (one).

Is 0 odd or even?

Even. Zero counts as even, because it can be split into two equal groups of zero.

If you have 0, how many more do you need to make 10?

10, because 0 + 10 = 10.

🏫 Classroom Activity

Show an empty basket or bowl and ask children how many items are inside — the answer is zero! Then fill it with a few toys and empty it again, counting down to zero each time to make the concept concrete.

🏠 Homeschool Activity

At snack time, eat crackers one at a time while counting down out loud — "three, two, one, zero!" — until the plate is empty. This turns an abstract idea into something your child can see and experience directly.
